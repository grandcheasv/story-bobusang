# 이야기 보부상

Next.js, TypeScript, Tailwind CSS로 만든 모바일 웹앱의 기본 프로젝트입니다. 현재는 시작 화면만 있으며 실제 기능은 없습니다.

## 내 컴퓨터에서 실행하기

1. 이 폴더에서 터미널을 엽니다.
2. 처음 실행하거나 `node_modules` 폴더가 없다면 `npm install`을 실행합니다.
3. `npm run dev`를 실행합니다.
4. 브라우저에서 <http://localhost:3000>을 엽니다.
5. 종료하려면 터미널에서 `Ctrl+C`를 누릅니다.

화면 내용은 `app/page.tsx`, 전체 화면 설정은 `app/layout.tsx`, 공통 스타일은 `app/globals.css`에서 수정할 수 있습니다.
